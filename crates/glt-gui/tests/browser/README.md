# 播放隔离的真实 DOM 回归

这里不是静态 HTML 快照。`playback.html` 在真实浏览器中挂载 5000 音符的
钢琴卷帘与分析画布，检查播放时 React 提交/静态绘制次数、指针移动和暂停、
尺寸变化、焦点键盘操作、撤销，以及隐藏分析面板的可见性回调。

1. 在 GUI 目录运行 `npm run dev`。
2. 启动专用测试 WebView2/Chromium，并启用 `--remote-debugging-port=9238`。
   不要连接用户正在编辑工程的窗口：测试会导航该实例的第一个页面。
3. 在 GUI 目录运行 `node scripts/browser-regression.mjs 9238`。
   失败或超时返回非零；成功输出 JSON 断言及播放阶段计数。

原生 GUI 的 WebView2 可以通过 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 注入调试参数。
测试后关闭该专用进程并移除环境变量。此页面不进入产品入口或发布包。

本测试使用模拟播放时钟，不证明音频后端时间精度，也不替代安装版全流程、
60 秒实播或 10 分钟长素材性能门禁。

## 工作区真实交互

另一个脚本 `node scripts/workspace-regression.mjs RESULT_DIR [CDP_PORT]` 用于专用的
Tauri 开发窗口（`npm run dev` 已启动、原生窗口加载同一 devUrl）。传入一个有音符的
现有结果目录，不要传媒体文件，也不要连接用户正在编辑的窗口。

它通过实际输入与按钮打开结果，验证规则数值、全选/删除/撤销、切换视图保留编辑、
面板折叠持久化与恢复默认布局，并用浏览器设备尺寸模拟检查常用控件可达。
测试中的音符编辑不发布；它会刷新专用窗口并恢复测试前的布局偏好。
失败或超时返回非零。尺寸模拟不是实际 Windows 安装版 DPI 验收。


## 恢复草稿、失败保护和真实发布

`node scripts/draft-regression.mjs RESULT_DIR [CDP_PORT]` 连接专用原生开发窗口，先将输入结果
复制到独立临时测试目录（跳过符号链接），所有编辑和故障注入仅针对副本。
需提供有可编辑音符与正常导出产物的结果，原生窗口的 worker 必须可用。
脚本覆盖 1 秒保存、重新加载恢复、图形横线拖动取消、取消替换、基准篡改造成的保存失败、
失败时阻止离开、导出版本选择，以及真实 worker 发布成功后清理草稿和源结果不可变。
失败会保留本地证据目录，不上传数据，不静默安装组件。

工作区交互脚本也使用独立结果副本，避免测试撤销/草稿污染传入的已发布结果。
这些开发窗口测试不替代真实安装版、WM_CLOSE、完整长素材或系统 DPI 验收。

## 原生播放与交互门禁

`node scripts/playback-gate.mjs RESULT_DIR NEW_REPORT_JSON [CDP_PORT] [SECONDS] [LABEL]`
只用于专用的**正式打包前端**窗口，不接受 devUrl。建议使用独立测试 profile；不要连接正在编辑的用户窗口。
数据集需要可编辑 Performance 与 preview.wav。默认连续测量完整长素材，然后执行缩放、视图切换、结果重载和横线拖动；不会发布音符编辑。

- 不改写应用时钟、invoke 或 requestAnimationFrame；通过 CDP 观察实际 IPC 响应和渲染指针。
- 只统计真正的 POST 命令，排除浏览器 CORS OPTIONS 预检；旧报告若把预检计入并发不能作为应用并发证据。
- 分别报告帧间隔、真实输入后的绘制反馈、带 IPC 时间不确定度的指针误差、定位恢复、DOM/监听器及 GC 后堆占用。
- 判断完整播放时同时检查实际测量时长、源文件起止位置和播放连续性；快进到末尾不能冒充完整播放。
- 60Hz 条件单独判定，180Hz 即使其他指标更好也不会记为 60Hz 通过。失败、缺失采样或环境不符必须保留。
- 输出 JSON 不覆盖已有测量；原始响应正文、路径参数和鉴权头不会写入报告。

门禁判定本身包含在前端 Vitest 测试中。性能报告只证明所测场景，不替代含人声素材音质听评、真实 Windows 系统缩放或所有操作入口审计。
